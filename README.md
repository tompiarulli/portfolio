# Tom Piarulli

My personal site: a short bio and links to where else I am, in one terminal window. Homage themes each change the colours, font and animated backdrop, like a green-phosphor White Rabbit with code rain. The page is prerendered so it loads instantly.

Built with React 19, TanStack Start, Tailwind 4, React Bits, Vercel, and Claude Code.

Want to run it locally or poke at the code? See [CONTRIBUTING.md](CONTRIBUTING.md).
