# Tom Piarulli

My personal portfolio, styled as a late-90s desktop OS and inspired by [Poolsuite](https://poolsuite.net). Draggable windows, a taskbar, and homage themes that each change the colours, font and backdrop, like a green-phosphor White Rabbit with code rain. Every page is prerendered so it loads instantly.

Built with React 19, TanStack Start, Tailwind 4, React Bits, Vercel, and Claude Code.

Want to run it locally or poke at the code? See [CONTRIBUTING.md](CONTRIBUTING.md).
