# Tom Piarulli

My personal portfolio, styled as a late-90s desktop OS and inspired by [Poolsuite](https://poolsuite.net). Draggable windows, a dock, pixel fonts, homage themes (starting with a green-phosphor White Rabbit), and a clock stuck in 1997. Every page is prerendered so it loads instantly.

Built with React 19, TanStack Start, Tailwind 4, React Bits, Vercel, and Claude Code.

Dock icons are from [Icons8 Flat Color Icons](https://github.com/icons8/flat-color-icons) (MIT).

Want to run it locally or poke at the code? See [CONTRIBUTING.md](CONTRIBUTING.md).
