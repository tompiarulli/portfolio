# Portfolio

Personal site styled as a late-90s desktop OS, inspired by [Poolsuite](https://poolsuite.net). Draggable windows, a dock, pixel fonts, swappable pastel themes. Every page is prerendered to static HTML so it loads instantly.

## Built with

React 19, TanStack Start, Tailwind 4, React Bits, Vercel, and Claude Code.

## Develop

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # prerender into .output/
pnpm typecheck
pnpm lint
```

See [CLAUDE.md](CLAUDE.md) for layout, conventions, and commit format.
