# Scripts

| Script           | Does                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Run                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `serve-prod.mjs` | Serves the Vercel build the way Vercel does, following the routes in `.vercel/output/config.json`; the end-to-end tests and Lighthouse start it.                                                                                                                                                                                                                                                                                                                 | `pnpm serve:prod`                           |
| `travel.mjs`     | Turns each folder of phone videos and photos in `assets/travel/` into a Travel channel: 960x540, cropped to 16:9, HDR tone-mapped, no sound or metadata, each named after its source file. Writes them to `public/travel/<channel>/`, which git keeps in LFS, and their list to `src/lib/travel.gen.ts`. Encodes only what changed and removes what lost its source; `--watch` keeps at it, `--force` redoes everything. macOS, with `brew install ffmpeg-full`. | `pnpm travel [channel] [--watch] [--force]` |
