# Scripts

| Script               | Does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Run                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| `serve-prod.mjs`     | Serves the production build as Cloudflare does: `vite preview` runs the built Worker and assets in Cloudflare's local runtime, behind a proxy that brotli-encodes text as Cloudflare's edge does. The end-to-end tests and Lighthouse start it.                                                                                                                                                                                                                                            | `pnpm serve:prod`                                    |
| `travel.mjs`         | Turns each folder of phone videos and photos in `assets/travel/` into a Travel channel from its approved masters: 960x540, cropped to 16:9, HDR tone-mapped, no sound or metadata, each named after its source file. Writes them to `public/travel/<channel>/`, which git keeps in LFS, and their list to `src/lib/travel.gen.ts`. Encodes only what changed and removes what lost its source; `--watch` keeps at it, `--force` redoes everything. macOS, with `brew install ffmpeg-full`. | `pnpm travel [channel] [--watch] [--force]`          |
| `travel-approve.mjs` | Approves Travel footage: plays each file in `assets/review/` in Quick Look and, for the ones Tom approves, writes a full-size master without sound or metadata to `assets/travel/` and records its SHA-256 in `travel.approved.json`. Runs only from a terminal. `--check` fails if any staged master isn't approved, or any file staged under `public/travel/` has no approved master; the pre-commit hook and CI run it.                                                                 | `pnpm travel:approve [channel]`, `pnpm travel:check` |
| `hooks.mjs`          | Installs the pre-commit hook that runs `pnpm travel:check`, into git's hooks folder beside Git LFS's. Run by `pnpm install`.                                                                                                                                                                                                                                                                                                                                                               | `pnpm install`                                       |
