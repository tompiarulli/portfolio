# Changelog

## 1.0.0 (TODO: launch date)

The first public release. Written by hand: the history before it is the build-up, and Release Please writes every entry after this one from the commits on `main`.

- A late-90s desktop in the browser: draggable windows, a dock, a menu bar, Shut Down, and a terminal with tab completion, history and a few easter eggs.
- Six themes, each with its own colours, font, menu mark, backdrop and clock date, applied before first paint.
- One prerendered page, plus a 404, with security and cache headers on every response.
- Keyboard and screen-reader accessible, WCAG AA contrast in every theme, and a phone layout with clear touch targets.
- CI runs lint, typecheck, unit tests, Playwright smoke tests and Lighthouse budgets on every push.
